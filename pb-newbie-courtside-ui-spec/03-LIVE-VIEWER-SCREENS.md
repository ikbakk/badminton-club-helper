## Between sets

Show Set 1 result and `Set 2 — Preparing…`. If substituted, Set 2 must display the actual lineup.

## Availability grouping

Order:

1. READY / Waiting
2. RESTING
3. AWAY
4. OUT

PLAYING players appear on the court card, not duplicated in READY. LEFT can be collapsed as `Finished tonight`.

## Privacy

Never expose session PIN, lease secrets, individual debt, raw uncertainty, audit logs, or algorithm diagnostics.
